# 🧱 DynaBlocks (2003/2004 Archive Fan Project)

Welcome to **DynaBlocks**, a historical simulation and non-profit archival fan project dedicated to recreating the nostalgic web interface of the 2003/2004 beta era.

This project was built from scratch.

## 🛠️ Features Implemented So Far

- [x] **Secure Authentication System:** User signup and signin via Supabase.
- [x] **Real-time Global Chat & Friends List:** Built using Supabase Realtime replication.
- [x] **Fully Functional Message Boards:** Retro-style subcategories with custom thread creation.
- [x] **Dynamic Global Ranking:** Top Point Holders table re-ordering live from the database.
- [x] **Secure Admin Control Panel:** Backed by database-level server-side functions (PL/pgSQL RPC) to protect point transactions against exploits.
- [x] **Digital Assets Catalog:** An integrated shop system powered by user reward points.
